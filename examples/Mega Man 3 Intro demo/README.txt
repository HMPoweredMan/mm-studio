Mega Man 3 Intro / Mega Man 3 - MM Studio 0.5.1 example

Open Mega Man 3 Intro - MM Studio.rpp, or import the MIDI and its tempo map.
Bank MSB 123/LSB 0; channels 1/2/3/10 = pulse 1/pulse 2/triangle/native noise.
Keep Strict NES hardware enabled and Play pads from MIDI disabled.
LOOP_START/LOOP_END enclose one verified repeat cycle after the one-time opening.
Loop start: 30.230048 seconds. End: 53.681056 seconds.
The original driver trace repeats attacks, gates, tempo and per-voice controls across two cycles.
Source notes, levels, duty, fine tune, glide, held pitch targets and held-program changes are retained in the MIDI.
This is an editable sequencing example, not a bit-identical console recording. Original game composition/data is Capcom material; see THIRD_PARTY.md.
