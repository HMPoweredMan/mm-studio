Dark Man / Proto Man stage theme - Mega Man 5

Requires MM Studio 0.5.0. Open the REAPER project or import the MIDI tempo map.
Full 24-bar loop; LOOP_START/LOOP_END mark the repeat range.
Channels 1/2/3/10 = pulse 1/pulse 2/triangle/native noise; bank 125/0.
Keep Strict NES hardware enabled and Play pads from MIDI disabled.
Native program changes, CC20 duty, source gates, level changes and glide/pitch bends are retained from the previously qualified Dark Man example. Neutral CC21, volume, expression and legato initialization are explicit.
This is an editable sequencing example, not a bit-identical console recording.
Original game composition/data is Capcom material; see THIRD_PARTY.md.
