Knight Man / Mega Man 6 - MM Studio example

Requires MM Studio 0.5.1. Import the MIDI with its tempo map, or open the supplied REAPER project.
Channels: 1 pulse 1, 2 pulse 2, 3 triangle, 10 native noise. Bank MSB 126 / LSB 0.
Keep Strict NES hardware enabled and Play pads from MIDI disabled.
The full intro leads into LOOP_START, followed by one complete main loop ending at LOOP_END.
REAPER project repeat is set to the main loop, preserving the intro on the first play.
MIDI retains seven tempo settings, source note gates, drum velocities, duty, level fades and the final glide phrase.
The VST uses its existing emulation/audio scheduling model; this is a sequencer transcription, not a bit-identical recording of console output.
MM6 programs remain MM6 programs. The current MM5 importer only accepts definitions already present in its target; this song needs additional MM6 definitions for a complete game import.
