# MM Studio in REAPER: ordinary single-track setup

Verified manually with MM Studio 0.5.0 and a fresh REAPER 7.82 configuration on 2026-11-03. No performance template, routing script, or preconfigured project was used.

## Record clicks on the plugin's drum pads

1. Insert one ordinary track (`Ctrl+T`). Click its **FX** button and add **VST3i: MM Studio 0.5.1** to the normal track FX chain.
2. Close the FX window temporarily. Right-click that same track's red record-arm button. Choose **Record: output > Record: output (MIDI)**. Leave the output mode at **Post-Fader** (the default).
3. In that menu, ensure **Monitor Input** is checked. Left-click the record-arm button so it lights red.
4. Reopen the FX window. Choose **Percussion / channel 10**, then the desired collection.
5. Click REAPER's transport **Record** button. Click the actual instrument pads in MM Studio.
6. Stop recording and choose **Save All** if REAPER asks whether to retain the recorded take. Double-click the new MIDI item to edit it.

No physical MIDI device is required for mouse clicks. **Play pads from MIDI** can remain off for this test. **Audition source** is a separate reference preview; use the actual pads to record hits.

REAPER normally records track input, which is upstream of the instrument. The output recording mode captures the notes and settings generated by MM Studio after that instrument runs.

## Existing projects with separate voice tracks

Find the track whose FX chain actually contains MM Studio. Configure and arm **that track** for MIDI output recording. A child track sending notes into a parent instrument cannot record MIDI generated inside the parent by recording its own output.

In the supplied Dark Man arrangement, the instrument is on the top parent track. **Native noise - MIDI 10** is a source track feeding that instrument. Arming only that child does not capture mouse clicks inside the parent plugin.

## If the piano roll appears empty

Native collection pad output uses channel 10 and MIDI pitches 0 through 15. These can be below the piano roll's current visible octave range. Show all MIDI channels (or channel 10) and scroll down to those pitches. A pad's displayed **In 10:36**, for example, is its controller trigger assignment; its native output pitch is shown separately in the pad description.

Program changes and CC messages accompanying each hit are expected: they preserve the source articulation. When recording additional takes over existing items, review **Monitor track media when recording** so previously recorded material is not unintentionally captured again.

## MIDI controller pads

Select the controller as the track's MIDI input, enable **Play pads from MIDI**, and send the displayed channel/note assignments (or right-click a pad to learn a different assignment). Keep MIDI output recording on the instrument track when you want to capture the translated native MM5 events.

## Verification evidence

A fresh single-track REAPER test project was created through ordinary UI actions. It contains two mouse-triggered notes on channel 10: pitch 4 / velocity 85, and pitch 2 / velocity 68, each with its matching note-off and preceding native bank/program/CC messages. The track's saved record mode is MIDI output. Dummy audio was used to isolate this MIDI capture test; this test does not qualify audio-device latency.

## Updating to 0.5.1

Install the complete `MM Studio 0.5.1.vst3` bundle and rescan. The five example projects have been rebuilt with this version. Older projects retain their previous plugin identity: replace the old instrument explicitly to use 0.5.1, then restore its settings. Keep the older plugin installed if you need those projects unchanged. The original single-track recording workflow above remains applicable.
